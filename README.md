# Power BI Superstore Sales Dashboard

## 📌 Project Overview

This project is my first Power BI mini project, developed as part of the Digital Egypt Pioneers Initiative (DEPI) – Data Analysis Track.

The project transforms raw Superstore sales data into an interactive Business Intelligence dashboard to analyze sales performance, profitability, products, and regional performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📊 Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- YoY Growth
- Average Order Value

## 📈 Dashboard Pages

### 1. Executive Dashboard
Provides an overview of the company's sales and profitability performance.

### 2. Product Analysis
Analyzes sales and profit across categories, sub-categories, and individual products.

### 3. Product Details
Provides detailed product-level analysis using Power BI Drill-through.

## 🔧 Data Preparation

The data was cleaned and transformed using Power Query, including:

- Data type correction
- Data cleaning
- Date handling
- Creating calculated columns
- Preparing the data for analysis

## 🧮 DAX

Several DAX measures were created for KPI calculations and time intelligence, including:

- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Average Order Value
- Running Total Sales
- Previous Year Sales
- YoY Growth %
